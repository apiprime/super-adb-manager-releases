# Changelog

All notable changes to **Super ADB Manager**. Download the latest release from the [Releases page](https://github.com/apiprime/super-adb-manager-releases/releases/latest) or from https://adb.apiprime.com.

## 0.6.1
- The menu bar now switches language with the rest of the app.
- System dialogs (file pickers, right-click menus) follow your Mac's language instead of always being English.
- Fixed a resource leak in the Logcat viewer when switching devices or log levels.

## 0.6.0
- Mirroring now tells you when the connection drops, instead of leaving a frozen frame on screen.
- Anonymous usage statistics are now off by default — you decide whether to turn them on.
- Licenses and third-party components are listed in Settings → About.

## 0.5.0
- QR code for the donation wallet address in the in-app support section.

## 0.4.0
- Automatic update notifications — a download badge appears in the sidebar when a new version is available.
- In-app support section with a USDT (TRC20) donation address.
- Anonymous usage statistics with an opt-out in Settings → Privacy.
- Support shortcut and version number added to the sidebar.

## 0.3.0
- MTP support — browse and transfer files on Kindle and other MTP devices.
- Symbol stripping in release builds.

## 0.2.0
- Real app names and colored icons in the app list.
- Mirroring quality panel — resolution, bit rate and FPS.
- Screenshot and screen-recording gallery.
- Country flags in the language picker.
- New DMG installer layout — drag to Applications.

## 0.1.0
- Screen mirroring with mouse and keyboard input.
- App, file and Logcat management; one-click developer options.
- Wireless ADB, seven accent themes, 15 interface languages.
- Signed and notarized DMG with embedded adb and scrcpy.
