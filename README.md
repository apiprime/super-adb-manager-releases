# Super ADB Manager — Releases

Public download hosting for **Super ADB Manager**, a free, native macOS app for ADB and Android screen mirroring (scrcpy): multi-device sidebar, in-app mirroring with touch/keyboard, app & APK manager, file manager, MTP/Kindle access, one-click developer options, advanced logcat, wireless ADB, and a screenshot/recording gallery.

- **Website & full feature list:** https://adb.apiprime.com
- **Latest download (Apple Silicon, macOS):** [SuperADBManager.dmg](https://github.com/apiprime/super-adb-manager-releases/releases/latest/download/SuperADBManager.dmg)

The app is **signed and notarized by Apple** (Developer ID), so it runs without Gatekeeper warnings. Every release includes a `.sha256` checksum for verification.

> This repository hosts release binaries only. The application source is maintained in a separate private repository. Bundled open-source components (scrcpy, adb, FFmpeg, libmtp, and their dependencies) are redistributed under their respective licenses — see **About → Licenses** inside the app, including the written offer for corresponding source of the GPL/LGPL components.
